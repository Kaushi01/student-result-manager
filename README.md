# Student Result Manager

A command-line based Student Result Management
System built using Python.

## Features

- Add student records
- View all registered students
- Check individual student results
- Calculate grades based on marks
- Handle missing student records
- Interactive menu-driven interface

## Technologies Used

- Python 3
- Dictionaries
- Loops and Conditional Statements
- Functions
- User Input and Output

## How to Run

1. Clone the repository:

   git clone YOUR_REPOSITORY_URL

2. Navigate to the project folder:

   cd student-result-manager

3. Run the Python program:

   python student_result_manager.py
